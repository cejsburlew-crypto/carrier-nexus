ELD / MOTIVE INTEGRATION

Connect your Motive (KeepTruckin) ELD system to pull live GPS, Hours of Service, DVIRs, and engine diagnostics.

Step 1 — Get Your Motive API Key

1

Log in to Motive Fleet Dashboard

Go to app.keeptruckin.com and sign in with your fleet admin account.

2

Open Account Settings → API Keys

Click your profile icon (top right) → Account Settings → scroll down to API Keys section.

3

Create a New API Key

Click + Create API Key. Give it a name like Carrier Nexus. Copy the generated key — it won't be shown again.

4

Paste the Key Below & Test

Enter your API key in the field below, then click Test Connection to verify. Data will populate automatically.

CORS Note & Proxy Setup

Browser security (CORS) may block direct calls to api.keeptruckin.com from this web app. If Test Connection shows a CORS error, the app falls back to simulated data automatically so you can see the layout. For live data, use one of these options:

A

Netlify Serverless Proxy (Recommended)

Add a netlify/functions/motive-proxy.js file to your repo. The proxy forwards requests server-side, bypassing CORS. Contact your developer to set this up — it takes ~15 minutes.

B

Motive Webhooks (Push Model)

Configure Motive to push events to a webhook endpoint (Settings → Webhooks in Motive). Webhooks bypass CORS entirely since data is delivered to your server.

C

Motive Mobile / Native App

The Motive fleet app for iOS/Android has no CORS issues and provides the same data. Use Carrier Nexus for reporting/operations and Motive app for real-time ELD monitoring.
