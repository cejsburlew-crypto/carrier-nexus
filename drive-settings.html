AUTO-ROUTING LOGIC
How Carrier Nexus decides where each document goes
When a new document appears in the inbox, Carrier Nexus checks in this order:
1
Match to a Rate Con / Load Number
Filename scanned for load numbers (e.g. 363402, RC-, BOL-). If matched → files under that load's driver folder → Rate Cons category.
2
Match to a Driver by Name
Filename scanned for driver names (Guillermo, Miguel, Nelson, Yosviel, etc.). If matched → that driver's folder → correct category.
3
Detect Document Category
Keywords in filename determine category: PERMIT → Permits, EXPENSE/EXP → Expenses, COI/INSURANCE → Personal, LEASE → Contracts, etc.
4
Extract Document Date
Date extracted from filename or file creation date. Used to tie document to the correct settlement period (bi-weekly, monthly).
!
Unmatched → Review Queue
If no driver or load can be determined, the document goes to the Review Queue (Doc Inbox page) for manual routing by admin.
Used to determine which settlement period a document's date falls into.
